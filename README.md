# XSHELF Homebrew tap

Install XSHELF with Homebrew:

```sh
brew install fugamante/tap/xshelf
```

XSHELF supports macOS Sequoia 15 or newer on native Apple Silicon (`arm64`)
and Intel (`x86_64`) Macs. Homebrew retrieves the matching prebuilt bottle
from the public GitHub Container Registry package.

Upgrade to the latest formula revision:

```sh
brew upgrade xshelf
```

Uninstall XSHELF:

```sh
brew uninstall xshelf
```
