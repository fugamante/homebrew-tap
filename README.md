# XSHELF Homebrew tap

Install XSHELF with Homebrew:

```sh
brew install fugamante/tap/xshelf
```

XSHELF supports macOS Sequoia 15 or newer on native Apple Silicon (`arm64`)
and Intel (`x86_64`) Macs. Homebrew retrieves the matching Developer ID signed and notarized archive
from the immutable GitHub release. Version `2026.10.07` does not include a new
bottle; the prior release's bottle evidence is retained below as history.

Upgrade to the latest formula revision:

```sh
brew upgrade xshelf
```

Uninstall XSHELF:

```sh
brew uninstall xshelf
```
